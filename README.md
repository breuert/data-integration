> This repository contains the resources of the **BSc Data Integration** course running in 2026/2027 at TH Köln - University of Applied Sciences. The course teaches the basics of working with data-driven questions. You’ll learn how to collect data from different sources, clean it up, and organize it into useful formats. From there, we’ll look at methods for exploring data and using statistics to test hypotheses. You’ll also gain skills in interpreting, visualizing, and presenting results so you can answer both research-based and real-world questions.

## Group project

Throughout the semester, you will collaborate with your team members and work on a group project. A shared Git repository is the technological basis to facilitate your collaboration. Follow these steps to get started:

* Create a Git repository on GitHub and include all team members as collaborators. As a student, you are eligible to gain access to the [GitHub Student Developer Pack](https://education.github.com/pack) that allows you to create an organization that hosts your group work (as an alternative to hosting the repository from a personal account).
* Invite [breuert](https://github.com/breuert/) as collaborator to your group repository.
* Additionally, send an e-mail to [breuert](https://github.com/breuert/) that contains:
  * your group / project name
  * a list of all team members including their full names, student identifiers, and their GitHub handles.
  
Make sure to have everything settled before the 1st milestone, since your roadmap is supposed to be shared from the Git repository. More details about the group project are shared in the slides.

## Milestones

The lecture series can be divided into three topical blocks. Each block ends with a milestone that helps you to structure and organize the group project. Each milestone builds on the one before, so start early and commit often.

* **1st milestone: Roadmap** (due 2026/11/13, end of block 1)
  * *Deliverables:* topic and dataset selection, with the license of every source; two or three research questions that your data can answer; a roadmap, i.e., your plan for the rest of the semester.
  * *Format:* Markdown documentation in the README of your group repository.
* **2nd milestone: Dataset** (due 2026/12/18, end of block 2, presented at the World Café)
  * *Deliverables:* an enriched dataset that combines several sources, e.g., open data and data you scraped; a pipeline prototype (skeleton code) that builds the dataset from the raw data; documentation of sources and licenses, cleaning steps, and a data dictionary.
  * *Format:* new dataset hosted online and a Jupyter notebook in your repository.
  * *Bonus:* +10 points for passing the World Café.
* **3rd milestone: Presentation** (2027/01/25, exam)
  * *Deliverables:* presentation of your results including slides; code repository and a demo of your running notebook; project documentation in the repository.
  * *Format:* exam with presentation, running notebook, open repository. Your repository is graded as it is at a deadline before the exam: **Jan 22, 2026 at 23:59 PM**. Later commits do not count.
